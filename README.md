# Web Wizard Studio v3.0

Open `index.html` in a modern browser. No build process is required. Google Fonts requires internet access; fallback fonts work offline.

## Included
- Editorial creative-agency welcome page
- Eight website archetypes
- Six visually differentiated design directions
- Live isolated iframe preview with 1200 / 810 / 390px viewports
- Editable hero copy, colour overrides and local reference-image accent sampling
- Hero and icon prompt copy
- Design blueprint, JSON tokens, CSS and prompt exports
- Standalone responsive HTML export

## Important
The website content is demonstration content. Buttons within generated pages navigate to local sections or a placeholder email. Replace sample copy, email and imagery before publishing. Image upload samples one accent colour; it does not recreate a screenshot or perform AI analysis. No backend, authentication, commerce processing or live analytics are provided.

## Files
`index.html`, `style.css`, `script.js`, `assets/` (reserved for future hero/icon art).
